# 2FA 自动识别器 - Chrome 浏览器扩展

自动识别两步验证（2FA）页面，扫描二维码保存密钥，本地生成 TOTP 验证码。

## 功能特性

- 🔍 **自动检测**：智能识别当前页面是否为2FA页面
- 📱 **二维码扫描**：自动扫描页面中的二维码，提取 otpauth:// 密钥
- ⌨️ **手动输入**：支持手动输入 Base32 密钥
- 🔢 **自动生成**：已登记页面自动显示 TOTP 验证码，每秒刷新
- 📋 **一键复制**：点击验证码即可复制到剪贴板
- 🌐 **域名管理**：默认按一级域名登记，支持手动配置保持完整地址
- 🔒 **本地存储**：所有密钥仅存储在浏览器本地，不上传任何服务器
- 🎨 **美观界面**：注入式浮动面板，支持深色模式
- 💾 **导入导出**：支持密钥的 JSON 格式导入导出

## 安装方法

### 开发者模式安装（推荐）

1. 打开 Chrome 浏览器，地址栏输入 `chrome://extensions/`
2. 开启右上角的「开发者模式」开关
3. 点击左上角「加载已解压的扩展程序」
4. 选择本扩展所在的文件夹（包含 manifest.json 的目录）
5. 扩展安装完成，会出现在扩展列表中

### 固定到工具栏

1. 点击 Chrome 右上角的扩展图标（拼图形状）
2. 找到「2FA 自动识别器」
3. 点击旁边的图钉图标，将其固定到工具栏

## 使用方法

### 场景一：新的2FA页面

1. 访问网站的两步验证设置页面（如 GitHub、Google、Twitter 等）
2. 扩展会自动检测页面，右上角弹出提示卡片
3. 点击「扫描并保存」自动扫描二维码，或点击「手动输入」
4. 确认要保存的密钥，可选择「保持完整地址」
5. 点击「保存选中」，密钥即保存到本地
6. 保存后自动显示当前验证码

### 场景二：已登记的页面

1. 访问已保存过密钥的网站
2. 扩展自动识别并显示验证码面板
3. 点击验证码即可复制
4. 验证码每30秒自动刷新，带倒计时进度条

### 场景三：手动管理

1. 点击扩展图标，查看当前页面状态和所有已保存密钥
2. 点击「设置与管理」进入完整管理页面
3. 可以手动添加、删除、导入导出密钥
4. 可以配置自定义域名（适用于二级域名售卖的服务）

## 域名匹配规则

### 默认行为
- 密钥按**一级域名**（eTLD+1）登记，例如 `github.com`
- 访问 `github.com` 的任何子页面（如 `github.com/settings/security`）都会匹配
- 访问 `gist.github.com` 也会匹配（因为同属一级域名）

### 保持完整地址
- 在添加密钥时勾选「保持完整地址」
- 密钥将绑定到完整域名，如 `account.example.com`
- 适用于使用二级域名售卖、不同子域名属于不同服务的情况

### 自定义域名配置
- 在设置页面的「自定义域名配置」中手动添加
- 添加后该域名的所有密钥都按完整地址匹配

## 检测机制

扩展通过以下信号综合判断是否为2FA页面：

| 信号 | 权重 | 说明 |
|------|------|------|
| otpauth:// 链接 | 高 | 页面中存在 otpauth:// 协议链接 |
| 二维码图片 | 中 | 页面中存在疑似二维码的图片 |
| 验证码输入框 | 中 | 存在6-8位数字输入框，autocomplete=one-time-code |
| 关键词匹配 | 低 | 页面标题/正文/URL包含2FA相关关键词 |

综合评分 ≥ 40 分时判定为2FA页面。

## 支持的算法

- **哈希算法**：SHA1（默认）、SHA256、SHA512
- **验证码位数**：6位（默认）、7位、8位
- **时间周期**：30秒（默认）、60秒
- 完全兼容 RFC 6238 (TOTP) 标准

## 隐私与安全

- 所有密钥存储在 `chrome.storage.local`，仅当前浏览器配置文件可访问
- 扩展不会向任何外部服务器发送密钥或验证码
- 扩展不包含任何追踪或分析代码
- 建议定期导出备份密钥文件
- 建议使用操作系统的用户账户保护浏览器数据

## 常见问题

**Q: 二维码扫描不出来怎么办？**
A: 部分浏览器的 BarcodeDetector API 可能不可用。可以选择「手动输入」，大多数2FA页面都会在二维码旁边提供「无法扫描？手动输入密钥」的选项。

**Q: 为什么有些页面没有自动弹出提示？**
A: 检测机制基于多种信号综合判断，可能存在漏检。你可以手动点击扩展图标，然后点击「重新扫描」或「手动添加」。

**Q: 换电脑了怎么迁移密钥？**
A: 在设置页面点击「导出」生成 JSON 文件，在新电脑的扩展设置页面点击「导入」即可。

**Q: 支持哪些浏览器？**
A: 支持所有基于 Chromium 的浏览器，包括 Chrome、Edge、Brave、Vivaldi 等。
